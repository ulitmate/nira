# /brag plan — Nira intro video

**What it is:** Nira, a free, privacy-first period and cycle tracker (web + mobile) with an AI assistant.
**Who it's for:** anyone who gets a period, and the women-led NGOs that support them.
**Angle:** period data is sensitive, so don't ask people to trust us: the code is open for anyone to read.
**News to announce (from the owner):** Nira is now open source · partnering with women-led NGOs · the Nira API powers
their programs · free.
**Hook:** "Your period data is nobody's business."
**Share caption:** see share-copy.txt.

## Tone & identity
`polished` with a punchy reveal. Nira Glass: near-black background, white type, ONE pink (#E0185C / #FF5C8A),
glass panels, system font → Inter. Real assets: design/web/tokens.css + components.css, and the real mobile
mockup (design/mobile/today.html, dark theme) for the product scenes. No gradients, no purple, no glows.

## Music
Original, composed in code (numpy). 120 BPM, D major, I–V–vi–IV (D–A–Bm–G), one chord per bar (2 s).
Bars 1–2 intro (pad + soft arp) → riser → drop at 4.0 s (kick, bass, hats, arp) → bar 10 breakdown (no kick)
for the "Free" line → back in → final D chord rings out. SFX (sheet whoosh, chip tap) are short pitched
notes/noise in key, mixed under the music. Every cut is on a beat.
